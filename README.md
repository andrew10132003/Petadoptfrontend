# 🐾 Pet Adoption Platform - Frontend

A responsive and user-friendly React application for browsing and adopting pets. Built with React, TypeScript, Vite, and Tailwind CSS.

---

## 🚀 Features

- 🏠 Home Page
- 🐶 Browse Available Pets
- 🔍 Search Pets
- ❤️ Add/Remove Favorites
- 📄 Pet Details Page
- 📝 Adoption Form
- 👤 User Registration
- 🔐 Login Page (In Progress)
- 📱 Responsive Design

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios
- React Router DOM

## ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Move to frontend

```bash
cd Frontend
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

---

## 🌐 API

The frontend communicates with the backend using Axios.

Default API URL

```
https://petadoptbackend-4dt0.onrender.com/api
```
