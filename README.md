# Pet Adoption Platform

Welcome to the Pet Adoption Platform! This project is designed to connect potential pet adopters with shelters and foster organizations, providing a comprehensive solution for pet adoption.

## Features

- **Pet Listings**: Organizations can create and manage detailed profiles for each pet, including information such as name, age, breed, size, color, and medical history. Users can upload photos and videos of pets and utilize search filters to find pets based on breed, age, size, and location.

- **Application Management**: Users can submit adoption applications directly through the platform. The system allows tracking of application statuses and facilitates communication between adopters and shelters. Shelters can review applications, request additional information, and schedule meet-and-greets.

- **User Reviews**: Users can leave reviews and ratings for shelters and pets, helping future adopters make informed decisions. The platform includes a system for filtering and displaying reviews.

- **Connecting Adopters with Shelters**: Tools are provided for potential adopters to contact shelters and foster organizations directly. A messaging system enables communication, and options for scheduling appointments or visits to meet pets are included.

- **Fostering Pets**: Users can sign up as foster parents and list pets they are currently fostering. Features for managing fostered pets, including profiles and status updates, are implemented, along with tools for shelters to coordinate with foster parents.

- **Search and Filtering**: Advanced search and filtering options help users find pets based on specific criteria, with features for sorting search results by relevance, location, and other parameters.

- **User Features**: Secure user registration and login functionalities are implemented. Users can manage their profiles, track applications, save favorite pets, receive notifications about new listings, and get updates on their application status.

## Tech Stack

- **Backend**: Node.js, Express, MongoDB (MERN stack)
- **Frontend**: React, TailwindCSS
- **Email Service Integration**: For notifications and communication

## Getting Started

### Prerequisites

- Node.js
- MongoDB

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/pet-adoption-platform.git
   ```

2. Navigate to the backend directory and install dependencies:
   ```
   cd pet-adoption-platform/backend
   npm install
   ```

3. Set up your environment variables by copying `.env.example` to `.env` and filling in the required values.

4. Start the backend server:
   ```
   npm start
   ```

5. Navigate to the frontend directory and install dependencies:
   ```
   cd ../frontend
   npm install
   ```

6. Start the frontend application:
   ```
   npm start
   ```
